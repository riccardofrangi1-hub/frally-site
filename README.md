# Sito demo - Psicologa fittizia (scherzoso)

## Avvio con npm (Prompt dei comandi)
1. Apri CMD nella cartella del progetto.
2. Installa dipendenze:

```cmd
npm install
```

3. Avvia il server locale:

```cmd
npm run dev
```

4. Apri il browser su:

`http://localhost:5500`

## Nota
`start-local.ps1` resta disponibile, ma non e' necessario se usi npm.
